# Lista Duplamente Encadeada - TypeScript

Implementação de uma **Lista Duplamente Encadeada** em TypeScript com interface web interativa.

## 🚀 Como Executar

```bash
npm install
npm start
```

A aplicação abrirá automaticamente em `http://localhost:1234`

## 📁 Estrutura do Projeto

```
trabalho_estrutura-de-dados/
├── src/
│   ├── index.ts                  # Implementação completa da Lista Duplamente Encadeada
│   ├── interface.ts              # Controle da interface HTML e event listeners
│   └── styles.css                # Estilos da interface
├── index.html                    # Interface web
├── package.json                  # Configuração do projeto
└── tsconfig.json                 # Configuração TypeScript
```

## 🎯 Funcionalidades Implementadas

### Inserção
- ✅ Inserir no início
- ✅ Inserir no fim
- ✅ Inserir em posição específica

### Remoção
- ✅ Remover do início
- ✅ Remover do fim
- ✅ Remover de posição específica

### Visualização
- ✅ Exibir em ordem normal
- ✅ Exibir em ordem reversa

### Utilitários
- ✅ Verificar se está vazia
- ✅ Mostrar tamanho
- ✅ Limpar lista

## 💻 Como Usar

1. Digite um valor no campo "Valor"
2. (Opcional) Digite uma posição no campo "Posição"
3. Clique nos botões para executar as operações
4. Veja os resultados na seção "Resultado das Operações"
